# cm-labs

Практические занятия по дисциплине «Конфигурационное управление».

РТУ МИРЭА, Институт информационных технологий, группа ИКБО-42-25.
Преподаватель: П. Н. Советов. Осенний семестр 2026/2027.

## Общее описание

Практическое занятие №1 «Командная строка»: простые действия с файлами
и каталогами в Linux из командной строки. Все 10 задач собраны в одном
скрипте [`src/pract1.sh`](src/pract1.sh) и вызываются как подкоманды.

Требования: Linux, bash, GNU coreutils, findutils, sed, tar.

## Структура репозитория

```
cm-labs/
├── src/
│   └── pract1.sh          # решения задач практики №1
├── tests/

├── run.sh                 # запуск задач, тестов и проверки

```

## Функции

| № | Команда | Описание |
|---|---------|----------|
| 1 | `users [файл]` | Отсортированный по алфавиту список пользователей из `passwd` (по умолчанию `/etc/passwd`) |
| 2 | `protocols [файл]` | 5 протоколов с наибольшими номерами из `/etc/protocols` в формате `номер имя` |
| 3 | `banner <текст>` | Вывод текста в рамке, размер рамки зависит от длины текста |
| 4 | `identifiers <файл>` | Все идентификаторы по правилам C/C++/Java без повторений |
| 5 | `reg <файл> [имя]` | Регистрация команды: права `755` и копирование в `/usr/local/bin` |
| 6 | `comments [каталог]` | Проверка комментария в первой строке файлов `.c`, `.js`, `.py` |
| 7 | `duplicates [каталог]` | Поиск файлов-дубликатов по содержимому, включая подкаталоги |
| 8 | `archive <расш> [каталог] [архив]` | Упаковка файлов с заданным расширением в архив `tar` |
| 9 | `tabs <вход> <выход>` | Замена последовательностей из 4 пробелов на табуляцию |
| 10 | `empty <каталог>` | Имена пустых текстовых (`.txt`) файлов в каталоге |
| — | `help` | Справка по командам |

Если аргумент в квадратных скобках не указан, используется значение
по умолчанию: текущий каталог или системный файл.

### Настройки

| Переменная окружения | По умолчанию | Назначение |
|----------------------|--------------|------------|
| `REG_DIR` | `/usr/local/bin` | Каталог, куда команда `reg` копирует программу |

## Сборка и запуск тестов

Сборка не требуется. Перед первым запуском:

```bash
chmod +x run.sh src/pract1.sh tests/test_pract1.sh
```

Запуск тестов:

```bash
./run.sh test
```

Проверка скриптов в [ShellCheck](https://www.shellcheck.net/):

```bash
./run.sh lint
```
